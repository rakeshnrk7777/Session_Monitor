Session Monitor Readme

Overview

The Session Monitor plugin records the XMPP client sessions that are currently connected to Openfire. For each authenticated session the Session Monitor admin page shows:

  • The JID, username and resource.
  • The stream ID, and the client IP address/hostname and TCP ports.
  • The session status and authentication state.
  • The TLS protocol and cipher suite in use, when the session is encrypted.
  • The session creation and last-active timestamps, and the current session duration.
  • The client and server packet counters, and the client's language.
  • The XEP-0092 software-version information reported by the client.
  • The current presence, and the detached/closed state.

The plugin also records session lifecycle events (SESSION_CREATED, SESSION_DESTROYED, ANONYMOUS_SESSION_CREATED, ANONYMOUS_SESSION_DESTROYED and RESOURCE_BOUND). The last 1000 events are retained in memory and shown at the bottom of the Session Monitor page. Lifecycle events are also written to session-monitor.log so they can be inspected offline.

A dedicated Server Info page shows the server uptime and start time, and which connections were initiated by the server (outbound server-to-server and client connections) versus those that were initiated remotely (inbound sessions and external components). The page also keeps a boot/restart history that survives Openfire restarts.

Installation

Copy session-monitor.jar into the plugins directory of your Openfire installation. The plugin will then be automatically deployed. To upgrade to a new version, copy the new session-monitor.jar file over the existing file.

This plugin requires Openfire 5.0.0 or later.

Configuration

No configuration is required: the plugin is active as soon as it is deployed. The plugin adds two pages to the admin console:

  • Server > Server Settings > Session Monitor — the live session inventory and the most recent lifecycle events.
  • Server > Server Settings > Server Info — server uptime and start time, the connection overview, and the boot/restart history.

The plugin maintains the following log files:

  • logs/session-monitor.log — plugin load/stop messages and session lifecycle events (logged at Debug level). The file rolls at 10 MB and up to 50 rolled files are kept.
  • logs/server-info.log — one SERVER_START/SERVER_STOP record per boot, used by the Server Info page to render the boot/restart history.

Warning

The session details recorded by this plugin are not obfuscated in any way. The Session Monitor page and session-monitor.log expose the usernames, JIDs, IP addresses and connection details of connected users. Restrict access to the admin console and protect the generated log files accordingly. The event history is kept in memory only and is cleared when the plugin or Openfire restarts.
