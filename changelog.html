Session Monitor Changelog

1.0.0 (August 18, 2026) — initial release.

  • Initial release of the Session Monitor plugin for Openfire 5.0.0.
  • Live inventory of current XMPP client sessions, including JID, username, resource, stream ID, client IP/hostname, TCP ports, session status, authentication state, TLS protocol/cipher, creation and last-active timestamps, session duration, client/server packet counters, language, XEP-0092 software-version information, presence, and detached/closed state.
  • Session lifecycle events (SESSION_CREATED, SESSION_DESTROYED, ANONYMOUS_SESSION_CREATED, ANONYMOUS_SESSION_DESTROYED, RESOURCE_BOUND) are shown in the admin console and written to session-monitor.log.
  • Dedicated Server Info page with server uptime, start time and a boot/restart timestamp history that survives restarts.
